Choices & dice

Choices insert a selected response into the composer. Dice support d4, d6, d8, d10, d12, d20 and d100 with an explicit Insert result action.

INTERACTION RULENothing sends itself.

Clicking a choice or inserting a dice result only edits the current draft. Furina preserves existing composer text and waits for the user to send normally.

INTERFACE + ROLEPLAY SOUND

Let the conversation make noise — only when you want it to.

Interface Sounds and Roleplay Sounds are separate systems with separate controls.

INTERFACE SOUNDSFurina UI feedback

Optional global sounds for panel actions, choices, dice, Quote/Remember and other interface events. OFF by default, with Soft, Digital and Mechanical test sets.

ROLEPLAY SOUNDSStory event cues

Per-conversation SFX with assistant-event detection, category controls, cooldowns, custom trigger phrases and optional direct-audio URL overrides.

1Enable RP Sounds

Open Full Atelier → Scene → RP Sounds. The master switch is OFF by default and saved per conversation.

2Choose automatic or manual

Automatic assistant detection can listen for explicit events such as thunder, knocks, footsteps, glass, gunshots, fire or heartbeat. Turn it off for a manual-only soundboard.

3Direct your own cue

Use ♪ RP SFX above the composer to queue up to three sounds for your next real user send. No sound marker is inserted into the message sent to Clank.

4Customize when needed

Disable categories, add custom trigger phrases or replace a built-in cue with a direct audio URL. Failed custom playback falls back to Furina's built-in cue.

♪
History stays quiet.

Roleplay SFX seed existing messages silently and listen for new assistant text, so opening an old horror conversation should not replay every door, thunderclap and gunshot in the transcript.

06
DEVELOPER BUILD NOTES

What to check while 1.3.2 is still in preview.

The most useful feedback is about behavior, not only whether a setting exists.

Standard chat remains normal

Nothing should send automatically. Speaker nameplates and sounds remain opt-in. Existing themes should not unexpectedly enable new cosmetics.

Streaming stays sane

Dice/choices survive rerenders, message entrances do not replay across history, and RP SFX do not machine-gun during streaming updates.

Conversation state stays isolated

RP Sounds and other conversation-scoped settings should follow the correct chat without leaking into unrelated conversations.

Special layouts are unchanged

The 1.3.2 feature work targets standard chat. Visual Novel and Phantom are intentionally outside this update's feature passes.

✓
If the preview behaves well, you can simply keep using it.

When a bug-fix build replaces the 1.3.2 ZIP, reload the unpacked extension and refresh already-open Clank tabs so the new content scripts are injected.

STABLE OR PREVIEW

Choose the build that fits you.

1.3.1 remains the stable download. 1.3.2 is for testing the newest standard-chat features while they settle.

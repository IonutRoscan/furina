◇ ALTERNATE INTERFACES

Same conversation. Different stage.

Visual Novel Mode and Phantom Chat replace the way the current conversation is presented while still using the real Clank conversation underneath.

Both interfaces are experimental. They are deliberately separated from Furina's everyday customization tools because they can replace the normal chat presentation instead of merely restyling it.

◇
You can still continue the conversation.

Both interfaces include a composer that sends through Clank's real composer flow rather than trying to reproduce Clank's network request independently.

05
EXPERIMENTAL STATUS

Know what “experimental” means here.

DOM changes can matter

Both interfaces read the current Clank page. Major upstream layout changes can affect detection.

Very long chats take more work

Large conversations can require rebuilding or refreshing the interface's local representation.

Images are source-dependent

Portrait and scene artwork availability depends on what Furina can resolve from the current character or scene.

Exit if something looks wrong

The normal Clank conversation remains the source of truth. Close the alternate interface and verify there first.

✓
These interfaces do not replace your saved chat.

They are presentation layers over the current conversation. Closing them returns you to the normal Clank view.

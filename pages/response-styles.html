Aa RESPONSE STYLE LIBRARY

Give the model a direction to write in.

Furina includes a library of ready-made prompts for Clank's Custom Response Styles, from Cinematic Roleplay and Horror to Slow Burn, Academy Focused and Visual Novel.

Furina does not secretly replace Clank's response-style system. It gives you a searchable library and copies the selected prompt so you can paste it into Clank's own Custom Response Style field.

Aa
Clank still owns the response style.

Once pasted and selected in Clank, the response style behaves as a Clank setting. Furina is the library and copy helper.

Writing style and story control solve different problems, so they can be combined.

They complement each other, but neither depends on the other.

Horror + Atmosphere

Use the Horror style for writing and a darker Furina theme/rain/ambience for presentation.

Slow Burn + Director

Use the style for gradual relationship pacing and Director Notes for specific boundaries or canon.

Ensemble + Knowledge Boundaries

Use the group style for cast participation and Furina knowledge rules for who knows what.

04
LIMITS & TIPS

Use styles as guidance, not guarantees.

5,000-character hard limit

Furina's library prompts are designed to stay within Clank's Custom Response Style limit.

One style cannot fix every scene

If a conversation changes tone, changing styles can be better than forcing one prompt to cover everything.

Director is more specific

Use Response Styles for broad writing behavior. Use Director for current rules, next-reply direction and story-specific guidance.

Persona is separate

A Persona describes who you are in the conversation. Response Style describes how the assistant should write.

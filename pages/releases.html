02
UPDATING

Keep the browser and tab in sync.

1Export anything important

Use the appropriate Theme, Full Setup, Story Bible or Miyabi backup before a major update or install-path change.

2Replace the installed folder's files

For an unpacked Chromium install, keeping the same folder path is the safest way to preserve the same extension identity.

3Reload the extension and Clank tab

Use Reload in the extension manager, then refresh any already-open Clank pages so they receive the new extension context.

4Check your important state

Confirm themes, conversation-specific state and story tools behave as expected before deleting your backup.

03
DIRECTION

Furina does not need infinite features.

The project direction is to prefer real usage, stability, maintainability and usability over adding features only for hypothetical completeness.

01Fix real problems first

Crashes, broken state, renderer issues and major compatibility problems should beat novelty.

02Keep systems understandable

Essentials and the Guidebook exist because a powerful feature is not useful if nobody understands where to find it.

03Let users drive expansion

Future features should earn their complexity through actual need.

✦ GETTING STARTED

Welcome to Furina.

Furina can do a lot. You don't need to learn all of it before having fun.

This guide covers the basics: installing Furina, opening the panel, choosing between Essentials and Full Atelier, and trying the most useful features without diving into every advanced control.

✦
New user recommendation

Start with Essentials. It uses the same underlying Furina settings as Full Atelier, but keeps the advanced controls out of the way until you want them.

01
INSTALLATION

Install Furina.

Furina currently uses a normal unpacked Chromium-extension workflow.

1

Download Furina

Download the current Furina 1.3.1 ZIP from this site.

Download Furina 1.3.1 ↓
2

Extract the ZIP

Furina must be extracted before the browser can load it as an unpacked extension.

ZIP → Furina folder
3

Open your browser's extensions page

In Chrome, Brave, Edge or another Chromium-based browser, open the browser's extensions manager.

Extensions → Manage Extensions
4

Enable Developer Mode

Turn on Developer mode on the extensions page.

5

Load unpacked

Choose Load unpacked, then select the extracted Furina folder containing manifest.json.

6

Open ClankWorld

Open a Clank conversation. Furina should initialize automatically on supported chat pages.

◆
Choosing the correct folder

When using Load unpacked, choose the folder where manifest.json is directly visible — not a folder above it.

storageSave Furina settings

The extension uses browser extension storage for themes, per-chat state, Director/Continuity data and other Furina settings.

clank.worldRun on ClankWorld

The current manifest's host access is limited to https://www.clank.world/* so Furina can add its client-side UI and behavior there.

i
Current Chromium requirement

Furina 1.3.1 declares Chrome 118 as its minimum Chrome version. Other Chromium browsers need an equivalent modern extension platform.

02
THE PANEL

Open the Atelier.

Furina appears on supported Clank chat pages. Use the Furina launcher to open the panel.

✦
Furina launcher Open the Atelier from your chat.

Furina remembers your selected panel mode, so you don't have to choose Essentials or Full Atelier every time you reopen it.

UPDATING

Moving to a newer Furina build.

Furina stores its settings through the browser's extension storage rather than inside the downloaded ZIP. For an unpacked install, the safest update is to keep the same installed folder path, replace its files with the new build, and use Reload in the browser's extension manager.

1 Download the new release
→
2 Back up, then replace the old folder's contents
→
3 Click Reload, then refresh Clank
!
Keep a backup when experimenting.

Furina includes Theme, Full Setup, Story Bible and profile exports for different kinds of data. Loading a newly extracted folder from a different path can be treated as a separate unpacked extension by the browser, so back up important state before changing install paths.

◆ CONTINUITY ENGINE

Long stories forget. Furina can remind.

The Continuity Vault stores important roleplay facts locally and helps Furina decide which ones are worth bringing back into the current context.

That can include relationships, injuries, possessions, secrets, world lore, promises, unfinished plot threads and other facts that matter over a long conversation.

◆
Furina does not increase Clank's real context window.

Continuity works by selecting useful reminders from information you've saved. It is a context management tool, not unlimited memory.

Open a blank capture editor from the composer when you already know the fact you want to save.

✓
Review before canon.

Automatic suggestions can wait in the Memory Inbox for review. Manual “Remember this,” Quick Memory, and remembered text selections instead open the memory capture editor so you can shape the fact yourself.

05
GOOD MEMORIES

Facts beat essays.

The most useful continuity memories are usually short, specific and easy to recognize later.

TOO VAGUE

Aya had a really emotional scene in the forest and many things happened which changed how she feels about everything.

Hard to match. Hard to reuse.
→
BETTER

Aya no longer trusts Ren after discovering he lied about the forest attack.

Specific relationship change.
One useful fact per memory

Smaller entries are easier for Furina to select independently.

Use names directly

Clear names and aliases make future relevance easier to determine.

Record the current truth

If something changes, update or archive the old state rather than stacking contradictions.
